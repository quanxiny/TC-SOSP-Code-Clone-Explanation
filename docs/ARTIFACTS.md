# Curated artifacts

Included evidence:

- `artifacts/pilots/C9_*`: natural-pair records for Grad×Input, adapted
  GNNExplainer, adapted SubgraphX, and TC-SOSP;
- `artifacts/pilots/C1--C7` and `C11--C13`: budgets, predictor checkpoints,
  semantic/attention controls, and objective ablations;
- `artifacts/pilots/C16--C18`: stochastic-explainer seed records;
- `artifacts/explanation_truth/C8`, `C10`, and `C15`: positive and negative
  transformation-truth records;
- `artifacts/comparisons/C*.json`: corrected paired statistics, robustness,
  objective, and runtime reports;
- `artifacts/explanation_cases/`: compact qualitative case indices.

The failed GCJ rebuilt-negative diagnostic is retained as an invalidated record
and is not included in positive effectiveness claims.

Excluded:

- predictor checkpoints and optimizer states;
- raw upstream datasets;
- reviewer identities, assignments, method keys, and responses.

Host-specific paths in public JSON copies are repository relative. Metric and
selection values are unchanged. `ARTIFACT_SHA256SUMS` verifies the release.
